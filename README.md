## Cấu trúc bài nộp

1. **Bài 1 đến Bài 5:** Nằm trực tiếp trong repository này (`git-basic-practice`).
   - Bài 1: Khởi tạo repository và commit đầu tiên (`index.html`, `style.css`, `notes.txt`)
   - Bài 2: Commit nhiều lần và kiểm tra lịch sử (`script.js`, cập nhật `style.css`, `notes.txt`)
   - Bài 3: Điều hướng checkout detached HEAD và thử nghiệm 3 kiểu reset (soft, mixed, hard)
   - Bài 4: Kết nối remote GitHub và push nhánh main
   - Bài 5: Đồng bộ hai chiều (clone, push file `about.txt`, pull file `README.md` từ GitHub)

2. **Bài 6 (Tổng hợp quy trình làm việc hoàn chỉnh):**
   - Được thực hiện tại repository riêng: **https://github.com/DK3XDK2/personal-portfolio**
   - Thể hiện đầy đủ quy trình: Khởi tạo -> Thêm section -> Viết style CSS -> Commit nhầm CSS hỏng -> Dùng `git revert` khôi phục an toàn -> Push lên GitHub.

3. **Báo cáo chi tiết:**
